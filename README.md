# CYBER-GUARD
CyberGuard AI+ is a Python-based cybersecurity toolkit that detects suspicious messages, phishing links, scam emails, and potentially dangerous files. It includes password checking, file integrity monitoring, security audits, and optional VirusTotal integration to improve digital safety.

## 🚀 Features

- 📩 **Scam Message Detection** – Analyzes messages for suspicious words, scam patterns, and warning signs.
- 🔗 **Phishing URL Analysis** – Identifies potentially dangerous links using URL-based indicators.
- 📧 **Email Threat Analysis** – Checks email content for suspicious characteristics.
- 📱 **Phone Number Risk Checking** – Helps identify potentially suspicious phone-number patterns.
- ⚠️ **Risk Score Assessment** – Provides a risk score and threat classification based on detected indicators.
- 🔍 **Threat Evidence** – Explains the warning signs found during analysis.
- 🛡️ **Safety Recommendations** – Provides practical advice to help users avoid scams.
- 🖥️ **Python GUI** – Offers a simple graphical interface for convenient use.

## 🛠️ Technologies Used

- Python
- Tkinter
- Regular Expressions
- Rule-based Threat Detection
- URL and Message Analysis

## 🎯 Project Objective

The main objective of Cyber Guard AI is to improve cybersecurity awareness and help users recognize common online fraud attempts before they interact with suspicious messages, links, emails, or phone numbers.

## ▶️ How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Install any required dependencies.
5. Run the GUI application using Python.

## 🔒 Disclaimer

Cyber Guard AI is an educational cybersecurity project. Its results are indicative, not definitive. It may produce false positives or miss sophisticated scams. Always verify suspicious communications through official channels.
